# Olist E-Commerce Data Analytics

## Project Overview

This project analyzes Brazilian e-commerce data from Olist
to understand sales, customers, products, payments,
delivery performance, sellers, and customer reviews.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Data cleaning
- Data preprocessing
- Data integration
- Sales analysis
- Product analysis
- Customer analysis
- Seller analysis
- Payment analysis
- Delivery analysis
- Review analysis
- Geographic analysis
- KPI analysis
- Dashboard creation

## Key KPIs

- Total Sales Value
- Total Orders
- Total Customers
- Average Order Value
- Average Delivery Time
- Average Review Score
- Late Delivery Percentage
