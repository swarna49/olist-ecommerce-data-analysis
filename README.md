# Olist E-Commerce Data Analytics

## Project Overview

This project analyzes Brazilian e-commerce data from Olist to understand
sales, customers, products, payments, delivery performance, sellers, and
customer reviews.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Data cleaning and preprocessing
- Data integration
- Sales, product, customer, seller, payment, and delivery analysis
- Review and geographic analysis
- KPI analysis
- Dashboard creation

## Key KPIs

- Total sales value
- Total orders
- Total customers
- Average order value
- Average delivery time
- Average review score
- Late delivery percentage
